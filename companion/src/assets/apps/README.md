# App artwork

A picture here named after a built-in profile's id (`figma.png`, `onshape.svg`, …; PNG, SVG or
WebP, square, transparent background, 256 px or more) is what the companion shows for that
profile in the sidebar, on Mode and in the profile's header, in place of the knob's 48 pixel
icon. The knob itself is not affected. See `src/appart.ts`.
